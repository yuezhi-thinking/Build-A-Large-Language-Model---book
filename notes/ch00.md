## 1. 程序做什么

`add(a, b)` 返回两个数相加的结果。`return a + b` 是程序本身。

## 2. 测试做什么

`self.assertEqual(add(1, 1), 2)` 检查实际答案是否等于预期的 2。测试通过只说明这一个例子通过，不代表程序在所有情况下都正确。

## 3. 怎么告诉 GitHub

任务文件放在 `.github/workflows/ch00-test.yml`。`push` 表示每次提交都自动检查；`workflow_dispatch` 表示也能手动运行。GitHub 临时准备 Linux 电脑，取出代码，安装 Python，然后执行：

```sh
python code/ch00/test_add.py
```

## 4. 观察通过和失败

打开仓库上方 Actions，点开一次运行，再点 test 和 Run addition test 查看输出。正确时会看到 `OK`。

实验：把测试代码中的 `return a + b` 改成 `return a - b`，点击 Commit changes 保存。GitHub 会自动重新测试。因为 1 - 1 = 0，而测试预期为 2，所以会出现 `AssertionError: 0 != 2` 和失败状态。

再把减号改回加号并保存，测试就会重新通过。
